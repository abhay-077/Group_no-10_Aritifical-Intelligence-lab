# Artificial Intelligence Laboratory

This repository contains the implementations of experiments performed as part of the **Artificial Intelligence Laboratory** coursework. The experiments cover fundamental concepts of Artificial Intelligence, including regression, search algorithms, game-playing strategies, knowledge representation, neural networks, and genetic algorithms.

## Experiments Performed

### Experiment 1: Linear Regression
- Implementation of Linear Regression using Python.
- Training a model using sample data.
- Prediction of continuous values.
- Evaluation using Mean Squared Error (MSE).

### Experiment 2: Classical Search Algorithms
- Depth First Search (DFS).
- Breadth First Search (BFS).
- A* Search Algorithm.
- Understanding graph traversal and pathfinding.

### Experiment 2B: Advanced Search Algorithms
- Greedy Best-First Search.
- A* Search.
- AO* Search.
- Hill Climbing Algorithm.

### Experiment 3: Logistic Regression
- Implementation of Logistic Regression.
- Sigmoid activation function.
- Binary classification.
- Model prediction and accuracy calculation.

### Experiment 4: Basic AI Search Problems
- 8-Puzzle Problem using search algorithms.
- 8-Queens Problem using Backtracking.
- Tic-Tac-Toe problem using game search.

### Experiment 5: Minimax Algorithm
- Implementation of the Minimax algorithm.
- Optimal move selection in Tic-Tac-Toe.
- Understanding adversarial search and game-playing strategies.

### Experiment 6: Perceptron Learning Algorithm
- Implementation of a single-layer Perceptron.
- Training using AND and OR logic gates.
- Understanding weights, bias, and the learning process.

### Experiment 7: Forward and Backward Chaining
- Implementation of Forward Chaining.
- Implementation of Backward Chaining.
- Rule-based reasoning and knowledge representation.

### Experiment 8: Genetic Algorithm
- Population initialization.
- Fitness function evaluation.
- Selection, crossover, and mutation.
- Finding an optimized solution using evolutionary computation.

## How to Run

Clone the repository:

```bash
git clone https://github.com/abhay-077/Aritifical-Intelligence-lab.git
```

Navigate to the project directory:

```bash
cd Aritifical-Intelligence-lab
```

Run any experiment using Python. For example:

```bash
python Lab_01_Linear_Regression/lab01_linear_regression.py
```

Replace the file path with the experiment you want to execute.
